# ToFetch Connect（浏览器扩展）

把浏览器里的下载链接一键送进 ToFetch，附带当前站点的 Cookie 与来源页
（Referer），登录墙、防盗链的链接也能下。

## 安装（Chrome / Edge）

1. 解压 `ToFetch-Connect.zip`（或直接用仓库里的 `extension/` 目录）。
2. 打开 `chrome://extensions`（Edge 是 `edge://extensions`），
   打开右上角「开发者模式」。
3. 点「加载已解压的扩展程序」，选择解压出的文件夹。
4. 点扩展图标旁的「选项」：填 ToFetch 地址（本机版保持
   `http://127.0.0.1:8077`；服务器版填它的地址，如
   `https://down.example.com`）和访问密码，点「测试连接」确认通了。

## 用法

- **右键链接** →「发送链接到 ToFetch」
- **右键页面** →「发送本页到 ToFetch」；点工具栏图标同样是发送本页
- **选中一段文字**（含链接）右键 →「把选中的链接发到 ToFetch」
- 选项里可开启「拦截浏览器下载」：浏览器新建的 http(s) 下载会被
  取消并转投 ToFetch（默认关，需要时再开）

发送成功时工具栏图标会闪一个 ✓，失败闪 !（多半是 ToFetch 没在运行，
或地址/密码不对）。

## 说明

- 扩展是可选外挂：不装它，ToFetch 本体的一切功能都不受影响。
- 发送链接时，扩展会读取**目标链接域名**的 Cookie 一并交给 ToFetch
  作为下载请求头（这正是能下登录墙文件的原因）；除此之外不收集
  任何浏览数据，也不向 ToFetch 以外的任何地方发请求。
- ToFetch 需正在运行；本机版先双击 ToFetch.bat 再发送。
