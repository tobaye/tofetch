ToFetch（Windows 版）使用说明
================================

【怎么用】
双击 ToFetch.exe 打开控制面板，服务会自动在后台启动（没有黑窗）。
点面板上的「打开下载界面」，在浏览器里添加和管理下载。
下载的文件默认存到：此电脑 > 下载 > ToFetch 文件夹。

【控制面板】
· 现在的状态：服务/引擎是否在跑、下载目录、版本。
· 打开下载界面 / 启动服务 / 停止服务：按钮会按当前状态自动禁用，
  不会重复启动。
· 关面板窗口只是最小化到托盘，后台继续下载；双击托盘图标或从
  托盘右键菜单可以再打开。

【本机集成】（面板里，或浏览器界面 设置 > 本机集成，两处同步）
· 磁力链接与 .torrent 文件关联：打开后点磁力链接、双击种子文件
  都进 ToFetch。开关状态是从系统实时回读的，开了就是真开了。
  若系统「默认应用」被别的软件占用，面板会提醒你去
  设置 > 应用 > 默认应用 里把 MAGNET / .torrent 改选 ToFetch。
· 开机自启：登录 Windows 后后台静默启动，不弹窗。

【停止与退出】（执行前都会先提醒后果）
· 停止服务：下载停摆，关联保留，点磁力仍可唤起；重新打开
  ToFetch 即恢复。
· 退出 ToFetch：停服务＋注销关联＋取消自启，全部还给系统。
  退出后无法用 ToFetch 下载，点磁力也不会再唤起。

【其他】
· 本包自带 Python 与 aria2 引擎，不用另装任何东西。
· 卸载 = 在面板里点「退出 ToFetch」，然后删掉整个文件夹即可，
  不留残留。
